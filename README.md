# Capstone Project

## Overview

This project is my capstone application built to demonstrate modern frontend development practices using AI-assisted development.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Node.js

## Goals

- Build a production-ready web application
- Practice AI-assisted software development
- Follow Conventional Commits
- Write maintainable and scalable code

## Getting Started

Install dependencies

```bash
npm install
```

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
