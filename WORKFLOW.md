# WORKFLOW

## Feature Chosen
Homepage with a hero section, a navbar with gallery filters, and a gallery presented in a Netflix-like style.

## Correctness
The Home page achieved a much stronger Netflix-style look thanks to precise, well-planned instructions. The code structure and standards are also better and are ready to scale immediately. However, some functionality is still incomplete or not working as expected because too many instructions were included.

Example:
- The color theme is strong.
- The Home page was implemented well, but it leaned heavily toward a Netflix-style design.
- The layout was responsive across different screen sizes.


## Accessibility
The precise prompt supported accessibility fairly well by using semantic elements, visible focus states, and meaningful labels. Keyboard navigation worked more reliably, and the structure was easier for screen readers to understand.

Example:
- Buttons were implemented as actual buttons instead of clickable divs.
- Empty and active states were easier to understand.

## Edge Cases
Because too many instructions were included in the precise or guided prompt, some functionality did not work properly, and some instructions may not have been scoped clearly enough.

Example:
- The search filter is not working.
- The gallery used a custom carousel instead of a well-suited plugin, so the layout did not match expectations.


## Review Effort
The Home page was built well and met my expectations. The project is ready for API integration and future scaling.

Example:
- The prompt produced a strong Netflix-style website.
- The project is ready for scaling.
- The site is ready for API consumption.

## Conclusion
This exercise shows that precise prompting produces better results. However, the instructions also need to be well scoped and focused on the task to avoid issues.
